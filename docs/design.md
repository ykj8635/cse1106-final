The design of the code is a smart classroom monitor to detect the temperature in a room and alert the user of it being out or within range of set temperature.
The design of the product is it has a set temperature range for the room and it ask the user to input a certain temperature and to check if its within the set range. Its also set up to ask the user if they want to 
change the temperature range of the room. Depending whether the number entered is within the set range it'll either turn the led light on or it'll turn it off.
The basic set up of the hardware/bread board is an led light connected to a 1k ohms resister that is connected to the rasberry pi with a wire that connected to the ground of the the pi and also a gpio pin.
